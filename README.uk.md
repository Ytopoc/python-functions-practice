# Python - практика функцій

Три короткі вправи на функції Python, роботу з датами, випадковими числами та dict/list comprehensions.

## Стек

- Python 3.12 (тільки стандартна бібліотека)

## Вправи

### `hw3_1.py` - днів від сьогодні

`get_days_from_today(date_str)` парсить рядок `YYYY-MM-DD` і повертає цілу кількість днів між цією датою і сьогодні. Від'ємне значення означає майбутню дату; повертається `None` (з повідомленням) при некоректному вводі.

### `hw3_2.py` - лотерейні числа

`get_numbers_ticket(min_, max_, quantity)` повертає `quantity` унікальних чисел у `[min_, max_]`, відсортованих за зростанням. Повертає порожній список з повідомленням, якщо параметри поза межами (`min_ < 1`, `max_ > 1000` тощо).

```python
print(get_numbers_ticket(10, 14, 5))   # [10, 11, 12, 13, 14]
print(get_numbers_ticket(1, 10, 10))   # [1, 2, ..., 10]
```

### `hw3_4.py` - найближчі дні народження

`get_upcoming_birthdays(users)` приймає список вигляду:

```python
[{"name": "John", "birthday": "1990.07.15"}, ...]
```

…і повертає тих, у кого день народження протягом наступних 7 днів, з перенесенням дати привітання на понеділок, якщо вона припадає на вихідні.

## Запуск

```bash
python hw3_1.py
python hw3_2.py
python hw3_4.py
```
